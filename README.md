# Hangar Vault

Закрытый магазин приложений: каталог catalog.json в этом репозитории, APK лежат в Releases.

## Первая сборка
1. На GitHub создай публичный репозиторий HopStore и загрузи в него все файлы из этой папки (кнопка Add file, Upload files; папку .github тоже).
2. Вкладка Actions, запусти build. Через пару минут внизу страницы запуска будет файл HopStore-apk. Скачай, распакуй, поставь на телефон.

## Добавить приложение
1. Releases, New release, тег v1, прикрепи APK (или любой файл), опубликуй.
2. Скопируй ссылку на файл (правой кнопкой по файлу) и добавь запись в catalog.json:
   {"id":"my-app","name":"Название","type":"app","version":"1.0","size":"12 МБ","desc":"Описание","icon":"","file":"ссылка"}
   type: app, game, tool, media или file. icon: ссылка на картинку, можно пустую.
3. Каталог в приложении обновится при следующем открытии (до 5 минут из-за кеша GitHub).

## Друзья
Друг присылает файл тебе, ты проверяешь и добавляешь запись. Репозиторий публичный, значит и ссылки на файлы открыты любому, кто их знает.

## Minecraft Bedrock
Файлы .mcworld, .mcpack, .mcaddon, .mctemplate кладёшь в Releases как обычно. В приложении у них кнопка «Открыть в Minecraft»: файл скачивается и сразу передаётся игре на импорт. Нужен установленный Minecraft Bedrock.

## Профили и значки
В catalog.json в блоке authors у каждого автора: name, bio, avatar (ссылка, можно пусто) и badge:
studio (звезда), verified (печать), mod (щит), friend (сердце), tester (ромб).
В записи приложения укажи "author": "id автора".

## Вид
Вкладка «Вид»: тема авто, светлая, тёмная; цвет (на Android 12+ можно с обоев); 7 фонов.
